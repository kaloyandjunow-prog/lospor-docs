# Издаване на V7

LOSPOR V7 се издава по реда на зависимостите и услугите. Не внедрявайте уеб
приложението или PWA, преди API да е в изправност на своя производствен домейн.

## Ред на хранилищата

1. Първо подайте, маркирайте и изтласкайте Core (за това издание `v7.3.0`).
2. Обновете API, уеб приложението, мобилното приложение/PWA и браузъра на базата
   данни към този неизменяем етикет на Core; обновете lock файловете и проверете
   чистите инсталации.
3. Подайте и маркирайте уеб приложението, мобилното приложение/PWA, браузъра на
   базата данни и документацията.
4. Подайте манифеста на изданието на API с точно шестте етикета.
5. Изтласкайте етикета на API последен. Неговото събитие автоматично стартира
   междухранилищната проверка на изданието спрямо тези неизменяеми препратки.

Проверката може да се стартира и ръчно преди етикетите като предварителен
преглед. Тя извършва чисти инсталации, мигрира временна база данни PostgreSQL,
изпълнява истински тестове за едновременност и износ, компилира всяко хранилище,
преминава през критичните потоци в уеб приложението и PWA и създава износ за
Android. Неуспешна автоматична проверка при етикет блокира внедряването и
издигането на изданието; поправете изданието и създайте нов етикет с корекция,
вместо да местите вече публикуван етикет.

## Внедряване на API

Създайте отделен проект във Vercel от `lospor-api`. Конфигурирайте базата данни,
адреса за преки миграции, споделената тайна за удостоверяване, имейла,
изкуствения интелект, CORS, планираните задачи, моментната снимка на опциите и
настройките за OMOP. Тайните принадлежат само на проекта на API.

Внедрете първо на временния адрес във Vercel. Проверете:

```text
/health/live
/health/ready
/v1/capabilities
/openapi.json
```

След това прикачете `api.lospor.org`, изчакайте HTTPS и повторете проверките
срещу производствения домейн. Компилацията на API изпълнява
`prisma migrate deploy`; никога не използвайте `prisma db push` в производствена
среда.

## Внедряване на клиентите

След като изправността и удостоверяването на API преминат:

1. Внедрете уеб приложението с
   `LOSPOR_API_INTERNAL_URL=https://api.lospor.org`.
2. Внедрете PWA с
   `EXPO_PUBLIC_API_BASE=https://api.lospor.org`.
3. Проверете входа, списъка със случаи, търсенето, запис на един случай и
   наследения съвместим път `/api/*` в уеб приложението.
4. Компилирайте APK/AAB за Android само след като проверките на живата услуга
   преминат.

## Връщане назад

Запазете достъпни производствените внедрявания на V6 и етикетите `v6.0.0`. Ако
API V7 се провали, преди клиентите да бъдат превключени, оставете уеб
приложението и PWA на V6. Ако клиентите вече са превключени, върнете назад API
и клиентите заедно, за да останат договорите им съгласувани.
