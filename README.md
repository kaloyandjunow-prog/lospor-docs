# Документация на LOSPOR — български

Това хранилище съдържа публичната документация за екосистемата LOSPOR:
клиничните Web и Mobile/PWA клиенти, API услугата, Database Browser и
архитектурата на локалните Hospital инсталации.

Публикуваната документация е достъпна на
[docs.lospor.org](https://docs.lospor.org). При промяна на поведение,
инсталационни изисквания, договори или процеси по издаване съответната
документация трябва да се актуализира заедно с кода.

## Локална работа

Използвайте командите, описани в `package.json`, за чиста инсталация,
локален преглед и продукционно изграждане. Не публикувайте документацията без
изрично разрешение.

# English

# LOSPOR Documentation

This repository contains the public documentation for the LOSPOR ecosystem:
the clinical Web and Mobile/PWA clients, the API service, Database Browser,
and the architecture of self-hosted Hospital installations.

The published documentation is available at
[docs.lospor.org](https://docs.lospor.org). Changes to behavior, installation
requirements, contracts, or release processes should update the corresponding
documentation alongside the code.

## Local development

Use the scripts declared in `package.json` for a clean install, local preview,
and production build. Do not publish the documentation without explicit
authorization.
